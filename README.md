Math Game (C++)

A C++ console-based math game built to practice structural programming concepts, logic building, and random operations.

🎮 Game Features

Difficulty Levels: Easy, Medium, Hard, Mix.

Operation Types: Addition, Subtraction, Multiplication, Division, Mix.

Game Summary: Displays overall results, number of right/wrong answers, and pass/fail status.

🛠️ Built With

Language: C++

Concepts Used: Procedural Programming, Structs, Enums, Random Functions, Control Flow.
